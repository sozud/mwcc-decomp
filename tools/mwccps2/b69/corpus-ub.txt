# constant (0x469310) or a float constant (0x469350) and writes type, +1,
# flags, rtype and data but not cost/hascall (+4/+5), so hascall is whatever
# an earlier allocation left in lalloc's arena (e.g. 0xFF). expandIR returns
# early for a float constant lui can build (and promote() turns an int

# TK_FLOATCONST). Proof: b69's bytes, read with gdb at 0x46931A and 0x46935A

# the research tree's NATIVE_CFLAGS=-DMWCCPS2_B69_HCSEQ (MWCCPS2_HCSEQ float, MWCCPS2_HCSEQI int)
# make every case below byte-identical; the same binary without the replay
# gives the baseline native's object. Evidence column: nonzero/total residue
